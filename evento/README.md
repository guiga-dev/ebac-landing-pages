# Módulo 22 — Landing page de evento

Evento fictício de aniversário em 5 de dezembro, data fornecida pelo usuário.
Projeto responsivo em HTML/CSS/JavaScript, com contagem regressiva para
5/12/2026 às 19h (UTC-3), programação, detalhes e arquivo de calendário ICS.
Não coleta nem transmite dados de visitantes. Local e programação demonstrativos.

Abra `index.html` ou sirva a pasta com `python -m http.server 8022`.
Publicação prevista em GitHub Pages após revisão do usuário.

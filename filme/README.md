# Projeto 4 — Landing page de filme

Página responsiva sobre Interestelar, criada em HTML, CSS e JavaScript.
Inclui navegação para seções, menu móvel acessível, FAQ expansível e arte espacial
original em CSS. Não depende de imagens ou vídeos de terceiros; as fontes usam
Google Fonts com fontes locais de fallback.

Abra `index.html` ou sirva a pasta com `python -m http.server 8021`.
Publicação prevista em GitHub Pages após revisão do usuário.
